 <h1>Creating a Virtual Machine on Microsoft Azure </h1>



<h2>Description</h2>

This project involves the creation of a virtual machine (VM) using Microsoft Azure. As part of the project, a virtual machine will be provisioned with a selected operating system (e.g., Windows Server or Ubuntu Linux)
<h2>Languages and Utilities Used</h2>

- <b>Microsoft Azure (Virtual Machines/Compute)</b> 


<h2>Environments Used </h2>

- <b>Windows 10</b> (22H2)

<h2>Program walk-through:</h2>

<p align="center">
Sign in to the Azure Portal: <br/>
<img src="https://i.imgur.com/AFpXHFY.png" height="80%" width="80%"/>
<br />
<br />
Create a Resource Group: Create a name for the Resource group and select a Region make sure you remember what Region you choose because you will have to use the same one to create the VM.
  Click Review and Create<br/>
<img src="https://i.imgur.com/WNEFmRR.png" height="80%" width="80%""/>
<br />
<br />
Create a Virtual Machine (VM): Search up Virtual machines in the search bar. When you get to this screen click create and you will see three options select the first one that says Azure Virtual Machines.  <br/>
<img src="https://i.imgur.com/L6m3CQ3.png" height="80%" width="80%""/>
<br />
<br />
Creating VM: The Resource group is going to be the one that was created earlier. then you will give the VM a name and select the Region that you choose when you made the resource group.  <br/>
<img src="https://i.imgur.com/oGZofou.png" height="80%" width="80%" "/>
<br />
<br />
For the Image section you will find the one that says windows 10 22H2 and for the Size section try to find the version that has 2 VCPUS that will be faster. <br/>
<img src="https://i.imgur.com/iqwvNWr.png" height="80%" width="80%" "/>
<br />
<br />
Create a user name and password but do not forget what it is because this is what you will need to start the VM up. scroll all the way down and check the box that says "I confirm" then Review and Create <br/>
<img src="https://i.imgur.com/YdwbkZI.png" height="80%" width="80%" "/>
<br />
<br />
Click Create <br/>
<img src="https://i.imgur.com/gxMTHm3.png" height="80%" width="80%""/>
<br />
<br />
Now go to your Virtual Machines section and you should see your created VM. <br/>
<img src="https://i.imgur.com/UWOn89P.png" height="80%" width="80%""/>
</p>
